# Code of conduct

## The short version

Be decent. Assume the other person is trying to help. Argue about the code, not
about the person writing it.

## What is expected

- Technical criticism is welcome and wanted — this project exists because
  somebody looked hard at it and found eight defects. Direct is fine. Personal
  is not.
- When you report a problem, say what you observed and how to reproduce it.
- When you disagree, say what you would do instead.
- People contribute in a second or third language. Read for meaning, not for
  grammar.

## What is not

Harassment, insults, or personal attacks. Sexualised language or imagery.
Publishing someone's private information. Sustained disruption of discussion.
Any of the above dressed up as "just being honest".

## Scope

Issues, pull requests, discussions, and any space where someone is representing
the project.

## Enforcement

Report to the repository owner through a private channel — a GitHub security
advisory works if nothing else is available. Reports are handled privately.

Responses range from a request to change behaviour, through removal of a
comment, to a ban. Whoever handles a report stays out of decisions about their
own conduct.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1, shortened to what this project can actually enforce.
